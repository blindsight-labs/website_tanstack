# Brand & Design-System Documentation

This repository (`website_tanstack`) is **public**. The brand and design-system source-of-truth documentation is maintained in a **private repository** to avoid exposing internal design decisions and proprietary guidelines.

## Access Brand & Design Docs

The authoritative brand and design-system documentation lives here:

**Repository:** [`blindsight-docs`](https://github.com/Webs-DiogoR/blindsight-docs)

### Clone Instructions

```bash
git clone https://github.com/Webs-DiogoR/blindsight-docs.git
```

This will give you access to all brand guidelines, design tokens, component specifications, and internal design artifacts.

## Why This Folder Only Contains This README

This folder is intentionally left with only this pointer README to:
- Prevent accidental recreation of brand content in the public repository
- Keep the repository structure clear (a reader expects `docs/brand/` to exist)
- Direct all internal contributors to the single source of truth

If you are maintaining design systems or brand docs, make changes in the private `blindsight-docs` repository, not here.
